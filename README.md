# PokéPython — Curso de Python con Pokémon

Curso interactivo de Python, de cero a temas avanzados, ambientado en el universo Pokémon.
Corre entero en el navegador, sin instalar nada.

## Cómo se abre

- **En línea:** https://ikamus.github.io/pokepython/
- **En local:** `python serve.py` y abrir http://127.0.0.1:8000

Doble clic en `index.html` no funciona: en `file://` el navegador bloquea los módulos ES y los `fetch()`, y la página queda vacía.
